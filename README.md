# LevelLens Teacher App

This project is a Vite + React app and is configured for static hosting on GitHub Pages.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`

## Build

Run `npm run build` to generate static files in `dist/`.

## Deploy to GitHub Pages

1. Push to `main` (or `master`).
2. In repository settings, set **Pages** source to **GitHub Actions**.
3. The workflow at `/home/runner/work/LevelLens/LevelLens/.github/workflows/deploy-pages.yml` builds and deploys automatically.
